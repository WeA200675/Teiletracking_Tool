# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue or pull request.

Use GitHub's **Report a vulnerability** option under the repository's Security tab to send a private report. If private vulnerability reporting is not available, ask the repository owner through a private contact channel to enable it before sending technical details.

Do not include production data, real device identifiers, credentials, certificates, or customer information in a report.

## Scope and response

The repository is a prototype and is not approved for production or BMW data. Security reports should include the affected branch or commit, impact, and a minimal reproduction using synthetic data. Do not test against BMW systems or other third-party infrastructure.
